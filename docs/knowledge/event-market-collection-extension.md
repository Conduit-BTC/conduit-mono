# Retired collection-based Event Market extension

The collection-based Event Market extension is removed. It does not provide a
reader, writer, checkout or handoff compatibility path. Old event links request
that the organizer repost using the current Event Market structure.

Use the [current Event Market contract](../specs/event-markets.md),
[lifecycle guidance](./event-market-lifecycle.md) and
[validation index](./event-market-validation-evidence.md). Ordinary product
collections and standard shipping remain separate supported concepts. Printable
event and merchant QR signs remain part of the current Event Market workflow.
