# Poppins

These unmodified WOFF2 files are the normal-style Latin subsets served by the official [Google Fonts Poppins CSS endpoint](https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700&display=swap), version 24.

The Latin subset covers the English UI copy and Western European accents. Additional scripts require their corresponding licensed font subset. Keep any future additions within the Poppins family where that family supports the script.

Conduit logo artwork remains an image/vector asset. It does not require a runtime Whyte font.

The shared UI uses Poppins for display, headings, body copy and controls. The system monospace stack remains available for identifiers and technical metadata. Font files are bundled locally; rendering does not contact Google Fonts.
