# Market home design study — DO NOT MERGE

This folder is a disposable, sample-data UI exercise, not a production feature.

- Edit the page, header, cards, artwork, fixtures, and CSS inside this folder.
- Keep the shared primitive bridge (`src/ui.ts`) and theme runtime imports intact.
- Do not edit `apps/market/src`, `packages/core`, `packages/ui`, production build
  configuration, workflows, or protocol schemas to support an experiment.
- No signers, relays, wallets, checkout, analytics, or real customer data.
- Use local images in `src/assets` and import them from `fixtures.ts`. No remote
  image services or external fonts. Keep the local-only content security policy.
- Keep labels, keyboard focus, semantic headings, and shared accessible controls.
- Run `bun run dev:study` from the repository root. Do not run `dev:market`, seed
  commands, or production services for this exercise.
- Use existing dependencies. The aim is a visual proposal, not theme architecture.
- Keep work in the design-study branch/fork. Do not merge or deploy this branch.
- Before sharing, run the study build and browser tests described in README.md.
  Supply desktop/mobile screenshots and a short explanation of design choices.
